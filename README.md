# DraftCog

DraftCog is a High-Performance, cloud-based rendering engine for real-time data visualization, optimized for dynamic, auto-scaling system architecture.

The key benefits of using DraftCog include:

- DraftCog is a High-Performance, cloud-based
- rendering engine for real-time data
- visualization, optimized for dynamic, auto-scaling

- php

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftCog.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DraftCog, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
